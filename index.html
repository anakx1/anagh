LVM Volume Expansion (Live Filesystem) Storage

Extend an existing logical volume on-the-fly and automatically resize the underlying XFS or EXT4 filesystem with -r.

# 1. Initialize PV and add to existing Volume Group
pvcreate /dev/sdb1
vgextend vg_data /dev/sdb1

# 2. Extend LV by +5G and grow filesystem simultaneously (-r)
lvextend -r -L +5G /dev/vg_data/lv_app

# 3. Verify filesystem block count and free space
df -hT /data/lv_app && lsblk -f
Persistent UUID Mounting & Stratis Pool Storage

Configure fail-safe persistent filesystem mounting via UUID in /etc/fstab and manage next-gen Stratis pools.

# 1. Retrieve UUID for block device
UUID=$(blkid -s UUID -o value /dev/vg_data/lv_app)

# 2. Append persistent entry to /etc/fstab with systemd nofail
echo "UUID=${UUID} /data/lv_app xfs defaults,nofail 0 0" >> /etc/fstab
systemctl daemon-reload && mount -a

# 3. Create Stratis pool & thin-provisioned filesystem
stratis pool create pool_rhel /dev/sdc
stratis fs create pool_rhel fs_docs
SELinux Custom Path File Contexts SELinux

Define persistent file context definitions in SELinux policy database using semanage and relabel target hierarchies.

# 1. Register persistent policy context rule
semanage fcontext -a -t httpd_sys_content_t "/custom_web(/.*)?"

# 2. Recursively apply label from policy database to disk
restorecon -Rv /custom_web

# 3. Inspect active SELinux security context
ls -ldZ /custom_web
SELinux Booleans & AVC Audit Logs SELinux

Toggle policy switches persistently with -P and extract human-readable remediation advice from audit logs.

# 1. Search and toggle boolean persistently (-P)
getsebool -a | grep httpd_can_network
setsebool -P httpd_can_network_connect 1

# 2. Query AVC denial logs from last 10 minutes
ausearch -m avc -ts recent

# 3. Generate diagnostic human-readable advice
sealert -a /var/log/audit/audit.log
RHEL 10 systemd Quadlets (Rootless) Podman

Manage declarative rootless containers natively through systemd unit files using RHEL 10 Quadlet automation.

# 1. Create Quadlet unit definition in user config
mkdir -p ~/.config/containers/systemd/
cat << 'EOF' > ~/.config/containers/systemd/web.container
[Container]
Image=docker.io/library/nginx:alpine
PublishPort=8080:80

[Service]
Restart=always

[Install]
WantedBy=default.target
EOF

# 2. Reload user daemon, start unit & enable linger
systemctl --user daemon-reload
systemctl --user enable --now web.service
loginctl enable-linger $USER
Systemd Calendar Timers (Replacing Cron) systemd

Schedule precise, journal-logged background maintenance using systemd .timer and matching .service units.

# 1. Timer unit configuration (/etc/systemd/system/backup.timer)
# [Timer]
# OnCalendar=*-*-* 02:00:00
# Persistent=true
# [Install]
# WantedBy=timers.target

# 2. Reload daemon, enable timer & check upcoming triggers
systemctl daemon-reload
systemctl enable --now backup.timer
systemctl list-timers --all
Shared Directory SGID & Default ACLs Security

Configure collaborative directories where all new files automatically inherit parent group ownership and user ACLs.

# 1. Establish SGID bit (2770) for automatic group inheritance
mkdir -p /shared_sales && chgrp sales /shared_sales
chmod 2770 /shared_sales

# 2. Assign active and default (inherited) POSIX ACLs
setfacl -m u:auditor:rx /shared_sales
setfacl -d -m u:auditor:rx /shared_sales

# 3. Verify effective access permissions
getfacl /shared_sales
User Account Expiry & Sudoers Policy Security

Create enterprise users with strict password expiration aging and dedicated drop-in /etc/sudoers.d/ permissions.

# 1. Provision user with secondary group and expiration date
useradd -G devops -e 2026-12-31 -c "Anagh VP" anagh

# 2. Enforce 90-day password aging policy & inspect
chage -M 90 -W 7 -I 14 anagh && chage -l anagh

# 3. Grant secure, validated sudo access via drop-in file
echo "%devops ALL=(ALL) NOPASSWD: /usr/bin/systemctl" > /etc/sudoers.d/99-devops
visudo -c -f /etc/sudoers.d/99-devops
Persistent firewalld Rules & Port Binding Network

Open enterprise application ports and services persistently across reboot and reload the firewall daemon.

# 1. Allow standard services and custom TCP port range
firewall-cmd --permanent --zone=public --add-service={http,https}
firewall-cmd --permanent --zone=public --add-port=8080-8085/tcp

# 2. Reload running firewall rules without dropping connections
firewall-cmd --reload

# 3. Confirm active zone configuration
firewall-cmd --zone=public --list-all
nmcli Static IP, Gateway & DNS Addressing Network

Configure static IPv4 network connection profiles and apply changes via NetworkManager CLI.

# 1. Configure static IP address, gateway, and DNS servers
nmcli con mod eth0 ipv4.addresses 192.168.122.50/24
nmcli con mod eth0 ipv4.gateway 192.168.122.1
nmcli con mod eth0 ipv4.dns "8.8.8.8 1.1.1.1"
nmcli con mod eth0 ipv4.method manual

# 2. Re-activate connection profile & inspect route table
nmcli con up eth0 && ip route show
