Redirection, pipes & text search

Essentials

Redirect output and errors, chain commands, and mine logs with regular expressions.

# Separate standard output and standard error
cmd > out.log 2> err.log

# Append output, discard errors, pipe into a pager
cmd >> out.log 2>/dev/null
ps aux | grep '[s]shd'

# Recursive, case-insensitive regex search with line numbers
grep -RniE 'error|failed' /var/log/

Find, archive & compress

Essentials

Locate files by name or age, then create, inspect, and extract compressed archives.

# Find files by name, type, and age
find /var/log -type f -name "*.log" -mtime +7

# Create and extract a gzip tarball
tar -czvf backup.tar.gz /etc /home
tar -xzvf backup.tar.gz -C /restore

# List archive contents without extracting
tar -tzvf backup.tar.gz | head

Links & standard permissions

Essentials

Create hard and symbolic links and set ownership plus ugo/rwx permissions.

# Hard link (same filesystem) and symbolic link
ln /data/report.txt /data/report-hard
ln -s /data/report.txt /data/report-soft

# Symbolic and octal permissions
chmod u=rw,g=r,o= /data/report.txt
chmod 640 /data/report.txt
chown anagh:devops /data/report.txt

# Verify
ls -l /data/report.txt /data/report-soft

Simple shell script

Essentials

Combine arguments, tests, conditionals, loops, and command substitution in one script.

#!/bin/bash
# /usr/local/bin/check-service.sh
svc="${1:?usage: check-service.sh SERVICE}"
if systemctl is-active --quiet "$svc"; then
  echo "$svc is running"
else
  echo "$svc is down" >&2
  exit 1
fi

for host in node1 node2; do
  ping -c1 -W1 "$host" >/dev/null && echo "$host ok"
done

echo "checked on $(date +%F)"

Partition disks (parted & fdisk)

Storage

Create a GPT label and partition, then refresh the kernel view before formatting.

# Inspect disks and create a GPT partition table
lsblk
parted -s /dev/sdb mklabel gpt
parted -s /dev/sdb mkpart app xfs 1MiB 5GiB

# Or use the interactive fdisk workflow
fdisk /dev/sdb

# Re-read the table and verify
partprobe /dev/sdb
lsblk -f

LVM from scratch

Storage

Build a volume group and logical volumes, then verify the physical volume, volume group, and logical volume stack.

# Create physical volumes, a volume group, and logical volumes
pvcreate /dev/sdb /dev/sdc
vgcreate vg_data /dev/sdb /dev/sdc
lvcreate -L 10G -n lv_app vg_data
lvcreate -l 100%FREE -n lv_logs vg_data

# Verify the stack
pvs && vgs && lvs

LVM volume expansion

Storage

Extend a logical volume on the fly and grow the XFS or EXT4 filesystem automatically with -r.

# 1. Initialize a PV and add it to the existing volume group
pvcreate /dev/sdb1
vgextend vg_data /dev/sdb1

# 2. Extend the LV by +5G and grow the filesystem simultaneously
lvextend -r -L +5G /dev/vg_data/lv_app

# 3. Verify free space and the block-device stack
df -hT /data/lv_app && lsblk -f

LVM snapshots

Storage

Capture a point-in-time copy of a logical volume, inspect it read-only, then remove it.

# Create a snapshot sized for the expected changed blocks
lvcreate -L 1G -s -n lv_app_snap /dev/vg_data/lv_app

# Mount read-only to inspect or back up
mkdir -p /mnt/snap
mount -o ro /dev/vg_data/lv_app_snap /mnt/snap
ls /mnt/snap

# Remove when finished
umount /mnt/snap
lvremove /dev/vg_data/lv_app_snap

Create & mount filesystems

Storage

Format XFS and EXT4 devices, mount them, and confirm the mount point and UUID.

# Make an XFS or EXT4 filesystem
mkfs.xfs /dev/vg_data/lv_app
mkfs.ext4 /dev/sdb2

# Mount and verify
mkdir -p /data/lv_app
mount /dev/vg_data/lv_app /data/lv_app
findmnt /data/lv_app
blkid /dev/vg_data/lv_app

Persistent UUID mount & Stratis

Storage

Configure fail-safe persistent mounting via UUID in /etc/fstab and manage next-gen Stratis pools.

# 1. Retrieve the UUID for the block device
UUID=$(blkid -s UUID -o value /dev/vg_data/lv_app)

# 2. Add a persistent fstab entry with systemd nofail
echo "UUID=${UUID} /data/lv_app xfs defaults,nofail 0 0" >> /etc/fstab
systemctl daemon-reload && mount -a

# 3. Install/start Stratis, then create a pool and filesystem
dnf -y install stratisd stratis-cli
systemctl enable --now stratisd
stratis pool create pool_rhel /dev/sdd
stratis fs create pool_rhel fs_docs
stratis fs list

Swap space

Storage

Create and activate swap on a logical volume, then persist it by UUID.

# Create and activate a 2G swap logical volume
lvcreate -L 2G -n lv_swap vg_data
mkswap /dev/vg_data/lv_swap
swapon /dev/vg_data/lv_swap

# Persist by UUID in /etc/fstab
echo "UUID=$(blkid -s UUID -o value /dev/vg_data/lv_swap) none swap defaults 0 0" >> /etc/fstab
swapon --show && free -h

# Remove: disable swap and delete the matching fstab line
swapoff /dev/vg_data/lv_swap
sed -i '\| none swap defaults |d' /etc/fstab

Persistent NFS mount

Storage

Install the NFS client, test the export, mount it, and add a resilient _netdev fstab entry.

# Install the client and query server exports
dnf -y install nfs-utils
showmount -e server.example.com

# Mount manually
mkdir -p /mnt/share
mount -t nfs server.example.com:/exports/share /mnt/share

# Persist across boots; _netdev waits for the network
echo "server.example.com:/exports/share /mnt/share nfs defaults,_netdev 0 0" >> /etc/fstab
mount -a && findmnt /mnt/share

# Unmount when no longer needed
umount /mnt/share

NFS server export

Storage

Share a directory with a lab subnet, re-export without a reboot, and open the firewall.

# Install and enable the NFS server
dnf -y install nfs-utils
systemctl enable --now nfs-server

# Export a directory (no_root_squash is lab-only)
mkdir -p /exports/share
chmod 2770 /exports/share
echo "/exports/share 192.168.122.0/24(rw,sync,no_root_squash)" > /etc/exports
exportfs -rav
showmount -e localhost

# Open the firewall for NFS clients
firewall-cmd --permanent --add-service=nfs
firewall-cmd --reload

SELinux custom path contexts

SELinux

Define persistent file-context rules in the SELinux policy database with semanage, then relabel the hierarchy.

# 1. Register a persistent policy context rule
semanage fcontext -a -t httpd_sys_content_t "/custom_web(/.*)?"

# 2. Recursively apply the label from the policy database
restorecon -Rv /custom_web

# 3. Inspect the active SELinux security context
ls -ldZ /custom_web

SELinux booleans & AVC audits

SELinux

Toggle policy switches persistently with -P and extract human-readable remediation advice from audit logs.

# 1. Search for and toggle a boolean persistently
getsebool -a | grep httpd_can_network
setsebool -P httpd_can_network_connect 1

# 2. Query recent AVC denial events
ausearch -m avc -ts recent

# 3. Generate human-readable diagnostic advice
sealert -a /var/log/audit/audit.log

SELinux modes & status

SELinux

Switch between enforcing and permissive at runtime and persist the mode across reboots.

# Inspect and switch at runtime
getenforce
sestatus
setenforce 0          # permissive until reboot
setenforce 1          # enforcing

# Persist across reboots
sed -i 's/^SELINUX=.*/SELINUX=enforcing/' /etc/selinux/config
grep '^SELINUX=' /etc/selinux/config

Inspect SELinux contexts

SELinux

Read file and process labels and confirm the policy mapping before relabeling.

# File, process, and policy mappings
ls -Z /var/www/html
ps -eZ | grep httpd
semanage fcontext -l | grep /var/www

# Apply the policy definition to disk
restorecon -Rv /var/www/html
ls -ldZ /var/www/html

systemd

Journal & persistent logs

systemd

Query the journal by boot, unit, priority, and time; make logs survive a reboot.

# Query recent boot and unit logs
journalctl -b -p err
journalctl -u sshd --since today
journalctl -f

# Persist journals across reboots
mkdir -p /var/log/journal
systemctl restart systemd-journald
journalctl --disk-usage

Boot recovery (rd.break)

systemd

Interrupt boot, remount sysroot read-write, reset the root password, and trigger an SELinux relabel.

# 1. At the GRUB menu, edit the kernel line and append:
rd.break

# 2. At the switch-root prompt:
mount -o remount,rw /sysroot
chroot /sysroot
passwd root
touch /.autorelabel
exit
exit

Kernel & bootloader (grubby)

systemd

Inspect and change the default kernel and kernel command-line arguments with grubby.

# Inspect the default kernel and all boot entries
grubby --default-kernel
grubby --info=ALL

# Add or remove kernel arguments across all entries
grubby --update-kernel=ALL --args="audit=1"
grubby --remove-args="audit=1" --update-kernel=ALL

systemd calendar timers

systemd

Schedule precise, journal-logged maintenance with a .timer and matching .service unit.

# 1. Timer unit configuration (/etc/systemd/system/backup.timer)
# [Timer]
# OnCalendar=*-*-* 02:00:00
# Persistent=true
# [Install]
# WantedBy=timers.target

# 2. The matching backup.service supplies the command to run
systemctl daemon-reload
systemctl enable --now backup.timer
systemctl list-timers --all

Cron & at jobs

systemd

Schedule recurring jobs with cron and one-time jobs with at, then inspect or remove them.

# User crontab: minute hour day month weekday command
crontab -e
crontab -l
30 2 * * * /usr/local/bin/backup.sh

# System-wide drop-in job
echo "0 3 * * 1 /usr/local/bin/weekly.sh" > /etc/cron.d/weekly

# One-time job
echo "/usr/local/bin/maintenance.sh" | at 23:00
atq
atrm JOB_ID

Account expiry & sudoers policy

Users

Create enterprise users with strict password aging and dedicated /etc/sudoers.d/ permissions.

# 1. Provision a user with a secondary group and expiry date
useradd -G devops -e 2026-12-31 -c "Anagh VP" anagh
passwd anagh

# 2. Enforce a 90-day password aging policy and inspect it
chage -M 90 -W 7 -I 14 anagh && chage -l anagh

# 3. Grant validated sudo access via a drop-in file
echo "%devops ALL=(ALL) NOPASSWD: /usr/bin/systemctl" > /etc/sudoers.d/99-devops
chmod 440 /etc/sudoers.d/99-devops
visudo -c -f /etc/sudoers.d/99-devops

SSH key authentication

Users

Generate an ed25519 key, install it on the remote host, and enforce key-only login.

# Generate a key and copy it to the remote account
ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519
ssh-copy-id anagh@server.example.com

# Log in with the installed key
ssh anagh@server.example.com

# On the server: correct permissions
chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys

# Disable password auth, validate, and reload
echo "PasswordAuthentication no" > /etc/ssh/sshd_config.d/50-no-password.conf
sshd -t && systemctl reload sshd

Sticky bit, SGID & POSIX ACLs

Security

Build collaborative drop directories where only owners can delete files, plus SGID directories with inherited ACLs.

# 1. Sticky Bit (1777): anyone creates, only owner deletes
mkdir -p /shared_drop && chmod 1777 /shared_drop

# 2. SGID (2770): automatic group inheritance & default ACLs
mkdir -p /shared_sales && chgrp sales /shared_sales
chmod 2770 /shared_sales
setfacl -m u:auditor:rx /shared_sales
setfacl -d -m u:auditor:rx /shared_sales
getfacl /shared_sales

Default permissions (umask)

Security

Read and set the umask, then confirm the resulting default modes for files and directories.

# Show the current shell umask
umask

# Set it for the current shell and persist it for a user
umask 027
echo "umask 027" >> ~/.bashrc

# Verify: files start at 666 and directories at 777
touch /tmp/umask-test && ls -l /tmp/umask-test
mkdir -p /tmp/umask-dir && ls -ld /tmp/umask-dir

Audit special permissions

Security

Locate setuid binaries and setgid directories that can affect privilege and collaboration.

# Find setuid files and setgid directories (single filesystem)

find / -xdev -perm -2000 -type d

Persistent firewalld rules

Network

Open application ports and services persistently across reboot, then reload the firewall without dropping connections.

# 1. Allow standard services and a custom TCP port range
firewall-cmd --permanent --zone=public --add-service={http,https}
firewall-cmd --permanent --zone=public --add-port=8080-8085/tcp

# 2. Reload running rules without dropping connections
firewall-cmd --reload

# 3. Confirm the active zone configuration
firewall-cmd --zone=public --list-all

nmcli static addressing

Network

Configure a static IPv4 profile with gateway and DNS, then apply it through NetworkManager.

# 1. Configure a static IP address, gateway, and DNS servers
nmcli con mod eth0 ipv4.addresses 192.168.122.50/24
nmcli con mod eth0 ipv4.gateway 192.168.122.1
nmcli con mod eth0 ipv4.dns "8.8.8.8 1.1.1.1"
nmcli con mod eth0 ipv4.method manual

# 2. Re-activate the profile and inspect the route table
nmcli con up eth0 && ip route show
